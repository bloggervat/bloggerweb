# Bloggervat.fun

Личная страница на HTML, CSS и JavaScript — без сборщика и сторонних зависимостей.

## Файлы

- `index.html` — разметка страницы.
- `style.css` — оформление и адаптивные стили.
- `main.js` — часы Владивостока и счётчик времени.
- `photo_2026-10-07_18-47-02.mp4` — видео в блоке профиля.

Чтобы открыть сайт, запусти локальный статический сервер в этой папке или открой `index.html` в браузере.
